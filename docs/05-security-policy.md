# 安全策略冻结

风险综合工具类型、参数、路径、网络目标、任务一致性、历史轨迹、可逆性和副作用，不得只看工具名。

| 风险      | 决策             | 语义                                           |
| --------- | ---------------- | ---------------------------------------------- |
| LOW       | FAST_EXECUTE     | 已授权且无显著副作用时快速执行                 |
| MEDIUM    | SANDBOX_CHECK    | checkpoint/pending、受控执行、深检后提交或回滚 |
| HIGH      | REQUEST_APPROVAL | 延迟请求人工授权；获批后仍走受控路径           |
| CRITICAL  | BLOCK            | 当前上下文中极高风险，不允许审批绕过           |
| FORBIDDEN | BLOCK            | 规则上无条件禁止的能力                         |

默认未知风险为 HIGH，默认策略为 REQUEST_APPROVAL。权限按实际步骤延迟申请，不一次性授予。规则引擎负责低成本信号；LLM/上下文深检只用于规则无法充分判断且可安全隔离的路径，二者都不能跳过 Policy Engine。
