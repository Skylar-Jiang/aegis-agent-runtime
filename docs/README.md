# 文档目录

- `design/`：架构、契约、状态机、工具规范、执行语义、API、事件和开发基线。
- `status/`：当前 Core/Runtime 交付、真实链路验证和成员交接记录。
- `demo/`：演示脚本与部署说明。
- `engineering/`：CI、验证命令和工程交接说明。
- `interfaces/`、`adr/`：冻结接口与架构决策。
- `phase3/`、`phase3.5/`、`v2-final/`：对应阶段的历史交付与冻结材料。
- `report-v2/`：作品报告草稿与实验章节。
- `evidence/`、`final-integration-assets/`：实验原始证据和截图。
- `history/`：早期基线和历史集成报告。

当前状态以根目录 `README.md` 和 `status/` 中日期较新的验证记录为准。
