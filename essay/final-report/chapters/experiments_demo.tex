\section{正式实验设计与数据链路}

本作品的正式实验由 raw 记录和由其自动生成的 derived 汇总共同构成；不手工填写实验数字。Safety、Graph 与 Rollback 的固定数据规模见表~\ref{tab:formal-data}. Safety 在确定性受控规则下验证风险、策略、审批和审计机制，不依赖 LLM 裁决形成正式结论；Graph 使用固定时延、确定性受控环境验证工程行为，不作统计显著性主张。

\section{工程验收与复现}
\label{sec:engineering-reproduction}

最终工程 Gate 的结果为 Ruff 通过、Pyright 0 errors/0 warnings、Backend 889 passed/8 skipped、Vitest 14 passed 和 Playwright 11 passed。正式实验重建和工程验收均以仓库根目录 README 中的锁定依赖命令执行：Ruff、Pyright、完整 pytest、前端 lint/typecheck/Vitest/build、Playwright，以及 \path{scripts/verify_final_experiments.py}。重建命令从正式 raw 生成并核验 Safety 225、Graph 18、Rollback 105 的 derived 结果；不改写 run ID，也不手工修改实验数字。

\begingroup\small
\begin{verbatim}
# Backend static checks and full test suite
py -3.11 -m ruff check backend/src tests
py -3.11 -m pyright --project backend/pyproject.toml
py -3.11 -m pytest -q

# Formal experiment reconstruction
py -3.11 scripts/verify_final_experiments.py \
  --report docs/final-integration-experiment-reconstruction.json

# Frontend and browser E2E checks
corepack pnpm --dir frontend lint
corepack pnpm --dir frontend typecheck
corepack pnpm --dir frontend test -- --run
corepack pnpm --dir frontend build
corepack pnpm --dir frontend exec playwright test -c ..\playwright.config.ts
\end{verbatim}
\endgroup
