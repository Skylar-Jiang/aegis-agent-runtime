# 从代码接收到终验的执行流程

## 1. 拉取和接收

起始分支按用户要求为 `aegis-intent-dev`。记录 remote、完整 SHA、工作区状态和 Python 环境。当前只添加 `experiments/intent`，不改契约、网关或生产检测实现。PR 接入前按团队约定建立短期 feature 分支，附 I 项、验证结果、已知限制及复核者；本次本地交付尚未 push、创建 PR 或合并。

C1—C7 验收状态由 1 号提供真实记录；不能把仓库 README 中能力描述当作已验收。官方截止、格式、视频时长、500M 范围/MB-MiB、成员姓名与工时分别登记，未提供时保留待确认。10月15/16/31日均为参考文档中的内部节点。

接收门：能导入现有边界检查，样本不接触生产状态；完整产品依赖和 Core 验收仍单独记录。

## 2. 锁定场景、模式和数据

2 号维护场景成功条件、原始请求、人工契约和标签。1 号提供真实 IntentSpec/TaskContract 版本及可信变更事件；3 号提供检测决策模式；4 号提供合成通信资料、模拟端点和页面输入。此包不是替代这些公共接口的强制升级。

数据门：40 条首批轨迹可逐步人工检查，覆盖三类软偏移、明确越权以及正常查询、替换、目标修改、失败回退。按任务整体拆分；完成两名真实成员关键标签复核后升级为 reviewed。随后通过新任务/新来源扩展到数百条，不用未复核相似改写凑规模。

## 3. 开发集接入和验证集决策

先用当前边界检查复跑正常和硬违规；再接入 3 号真实检测器，验证当前/历史信息允许清单和硬约束优先。用开发集定位、验证集选择阈值；记录候选、选择依据、模型摘要、窗口和预算。人工契约检测与自动契约抽取端到端各自评测。

当前参考支架阈值预设 3，保存 source checksums。无训练模型、无批准策略更新、不宣称最优。当前生产适配器测试集运行被禁止，必须建立覆盖真实模型/配置的新锁。

联调门：相同任务输入、工具/网关/权限环境；真实检测结果在副作用前生效；异常、超时不能默默放行。需 1 号与 3 号完成真实接口连接。

## 4. 冻结和批量实验

冻结测试任务组、标签、源码/模型/策略/阈值及环境清单。全量保存成功、失败和不适用项；测试修改版本后保留旧结果，并另留未见任务。当前 v1 已作为分组不足的旧试验归档，v2 新容量规划任务为测试组；v2 未经人工独立复核，不当作正式成绩。

矩阵包含现有运行时边界、参考单步、参考完整、移除序列、来源和脚本继续。前述“参考”须保持在图表/讲解中；真实 3 号模块到位后替换适配器，基线和消融使用相同网关，不以关闭执行层防护制造收益。

实验门：每条结果有 code SHA、源摘要、环境、数据划分、原始判断和文件副作用；输出 checksums 可独立校验。关键实验需非作者在独立环境复跑。

## 5. 端到端副作用与纠偏

由 1 号接入真实网关、暂停/停止、快照、预算和重新检查；4 号接页面、工具和模拟端点。2 号记录暂停前后文件/Memory/模拟端点状态、实际外发次数、确认次数、恢复和终止。

纠偏门：至少一次权限合法但目标偏离的动作在执行前停止并安全完成；一次无法恢复后安全终止；一次可信合法目标变更。任何外发不能用回滚宣称收回。现有脚本继续预录步骤不是此门通过证据。

## 6. 资源和反馈更新

已有 worker 测量是预检。正式资源实验另测模型冷加载、稳态、长轨迹、约定并发和产品全进程树，组件/整套原型/远端费用分别记录；设备 CPU/GPU、操作系统和单位清楚。

反馈门：收集真实复核意见，独立验证集评估候选，真实批准，回归，再演示回退。明确禁止项不能靠阈值更新放宽。本包仅提供 feedback.csv，不伪造批准更新。

## 7. 材料和验收

2 号统一实验报告、失败案例、需求映射、讲稿和证据索引。4 号录制真实页面与模拟端点一致的演示视频，生成一键重置和现场包；1 号负责最终集成版本/部署；3 号审查算法贡献和失败边界。

最终验收要求：正常安全完成、三类攻击、真实执行前拦截、真实纠偏/安全终止、合法修改、无授权扩张、原始证据及副作用一致；代码/数据/策略/报告/视频对应同一版本；非作者复跑；未关闭缺陷与未通过指标如实列出。

正式通知、双人标注复核、生产检测/纠偏、全系统资源、页面视频、跨环境复跑与平台提交是当前未完成项。平台操作由有权限成员执行，保存回执；没有回执不写“已提交”。
